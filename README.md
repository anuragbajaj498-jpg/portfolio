# Mayank Goyal Portfolio

A modern personal portfolio website showcasing my skills, education, projects, and AI-focused work as an AI-ML engineer.

Live demo: https://portfoliofinalassesment.vercel.app/

## About
This portfolio was built to present my profile, technical capabilities, and selected projects in a clean and engaging format. It includes sections for:

- About me
- Skills and technologies
- Education
- Project highlights
- Contact information
- Interactive AI assistant section

## Tech Stack
- HTML
- CSS
- JavaScript

## Features
- Responsive single-page portfolio layout
- Search and filter for projects
- Theme toggle for light/dark mode
- Modern glassmorphism-inspired design
- AI assistant UI for portfolio interaction
- Mobile-friendly design

## Run Locally
1. Clone the repository
2. Open `index.html` in a browser, or run a local server:

```bash
python -m http.server 8000
```

3. Open `http://localhost:8000` in your browser.

## Project Structure
- `index.html` — main portfolio structure
- `style.css` — styling and layout
- `script.js` — interactivity
- `chatbot.js` — AI assistant behavior
- `chatbot.css` — styling for the chatbot
- `config.js` — configuration values
